# Modul4_xml

Single-activity app using fragments and a navigation graph.

## Quick start

- Open the project in Android Studio.
- Build and run the `app` module on an emulator or device.

## Notes

- `MainActivity` hosts a `NavHostFragment` in `activity_main.xml`.
- Navigation is defined in `app/src/main/res/navigation/nav_graph.xml`.
- `MainFragment` shows the list; `DetailFragment` shows the selected item.
